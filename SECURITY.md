# Security policy

## Reporting a vulnerability

Please **do not** open a public issue. Report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository (private vulnerability reporting).

You can expect an acknowledgement within 5 business days. We will coordinate a fix and disclosure timeline with you.

## Scope

hashspan never signs or broadcasts transactions and needs no private keys. Relevant issues include, for
example, leaking data that the configured privacy mode should redact, or instrumentation altering the result of a
user's call.

## Supported versions

Only the latest minor release receives security fixes while the project is below 1.0.
